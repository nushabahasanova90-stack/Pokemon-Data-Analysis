# Pokémon Data Analysis

## Project Overview

This project analyzes a Pokémon dataset using Python and Pandas to explore Pokémon characteristics, types, statistics, and performance patterns.

The analysis focuses on exploring the dataset, identifying relationships between attributes, and generating insights through data visualization.

## Project Objectives

- Explore and understand the Pokémon dataset
- Analyze Pokémon statistics and characteristics
- Compare legendary and non-legendary Pokémon
- Analyze Pokémon types and generations
- Explore relationships between Pokémon attributes
- Identify patterns using statistical analysis and visualizations

## Analysis Performed

- Data exploration and descriptive statistics
- Data cleaning and missing value analysis
- Grouping and aggregation using Pandas
- Correlation analysis
- Comparison of legendary and non-legendary Pokémon
- Pokémon type and generation analysis
- Data visualization using charts and plots

## Key Skills Demonstrated

- Python
- Pandas
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Statistical Analysis
- Correlation Analysis
- Data-driven Insight Generation

## Tools Used
